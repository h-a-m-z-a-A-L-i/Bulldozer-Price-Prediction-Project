# Bulldozer Price Prediction

Predict used bulldozer sale prices with an end-to-end machine learning workflow, from raw tabular auction data to feature engineering, model training, and regression evaluation.

## Project Overview

This project builds a complete regression pipeline to estimate bulldozer prices using historical sales data. It covers data cleaning, handling mixed feature types, training tree-based models, and evaluating performance with practical metrics for real-world price prediction.
